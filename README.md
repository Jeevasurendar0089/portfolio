# Jeevasurendar Muthukrishnan — Portfolio

A lightweight, responsive personal developer portfolio built with semantic HTML, CSS and vanilla JavaScript.

## Run locally

From the project directory:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/`.

No build step or dependency installation is required.

## Structure

- `index.html` — main portfolio
- `css/` — responsive and visual styles
- `js/` — theme and UI behavior
- `assets/icons/` — local favicon/icons
- `assets/resume/` — resume PDF
