CDN

Operated the production CDN, configuring VPN, Linux Netplan networking and point-to-point links between CDN and origin servers.

Key engineering decisions

  • Independent services. Architected as independently deployable Node.js microservices, designed for scalability and fault tolerance.
  • Serverless request path. API layer on API Gateway and Lambda, removing always-on servers from the request path.
  • Failure isolation. SQS queues and WebSocket channels with retries and failure handling, so one failing service does not stall the rest.
  • Two-tier caching. Redis for application data and Nginx for HTTP responses to cut repeat load on origin systems.
